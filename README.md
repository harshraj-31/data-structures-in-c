# Data Structures in C

A collection of Data Structures programs implemented in **C** as part of the MCA Semester 2 laboratory coursework.

The repository is organized by topic and includes fundamental data structure implementations, searching and sorting algorithms, recursion, and practical assignments completed during the course.
